# Live S manual test checklist

Use an empty Codex composer and a disposable chat.

## Bottom dial Voice Chat

- [ ] Rotate left and confirm reasoning effort decreases.
- [ ] Rotate right and confirm reasoning effort increases.
- [ ] Press the bottom dial once and confirm Codex Voice Chat starts.
- [ ] Press the bottom dial again and confirm the active Voice Chat ends.
- [ ] Turn the dial after ending Voice Chat and confirm reasoning adjustment still works.

The press action sends the configured `Ctrl+Alt+Shift+V` shortcut for Codex's `composer.startVoiceMode` command. The Commands-page Dictate button remains available for text transcription.
